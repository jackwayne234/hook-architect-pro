Hook Architect Pro - How to Open

What it does:
Hook Architect Pro helps turn a YouTube transcript or pasted script into short, curiosity-driven hook ideas for videos, posts, and marketing content.

How to open:
1. Extract the ZIP.
2. Open the Hook Architect Pro folder.
3. Double-click: Open Hook Architect Pro
4. If your Linux desktop asks, choose Run or Run as Program.

Setup inside the app:
1. Choose Cloud (Easy) or Local (Private).
2. Cloud mode: paste your own Groq API key.
3. Local mode: enter your local OpenAI-compatible server URL, API key value, and model name.
4. Click Save and Launch.

Still required:
- 64-bit Linux desktop environment
- Internet when using Cloud mode or fetching YouTube transcripts
- Your own Groq API key for Cloud mode, or a local OpenAI-compatible server for Local mode

Privacy note:
- In Cloud mode, transcript text is sent to Groq using the API key you provide.
- In Local mode, transcript text is sent to the OpenAI-compatible server URL you configure.
- The app package does not include a shared API key.
- Do not paste private transcripts unless you trust the selected AI provider or local server.

Troubleshooting:
If the app does not open, re-extract the ZIP and try again.
A technical launch log is saved at:
/tmp/hook_architect_launcher.log
